Política de Privacidade — Grana Exposta Studio

Última atualização: 29 de setembro de 2026

O Grana Exposta Studio é uma ferramenta interna, de uso exclusivo do dono do canal Grana Exposta no YouTube, que roda no computador do próprio dono. Ela produz os vídeos do canal e, com autorização do dono, os envia ao YouTube e lê as métricas do canal. O app não tem outros usuários e não é oferecido ao público.

Serviços de API do YouTube

Este app usa os Serviços de API do YouTube (YouTube API Services). Ao usá-lo, você concorda com os Termos de Serviço do YouTube. O tratamento de dados pelo Google segue a Política de Privacidade do Google.

Quais dados o app acessa

  • Envio de vídeos (youtube.upload): envia os vídeos e as miniaturas produzidos pelo próprio app para o canal do dono.
  • Leitura do canal (youtube.readonly): lista os vídeos do próprio canal (título, data, duração, visualizações).
  • Métricas (yt-analytics.readonly): lê as métricas agregadas dos vídeos do próprio canal (visualizações, tempo assistido, retenção, taxa de cliques, origem do tráfego).

O app não acessa dados de outros canais nem dados pessoais de espectadores. As métricas do YouTube Analytics são agregadas e não identificam pessoas.

Como os dados são usados

As métricas servem apenas para o dono avaliar o desempenho dos próprios vídeos e melhorar os próximos. Os dados não são vendidos, compartilhados com terceiros nem usados para publicidade.

Armazenamento

O token de acesso e as métricas ficam só no computador do dono, numa pasta local que não é publicada nem sincronizada com servidores do app (o app não tem servidores). As métricas são atualizadas periodicamente e podem ser apagadas a qualquer momento.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento pelo botão Desconectar do app (que também revoga o token no Google) ou pela página de permissões da Conta Google. Depois de revogado, o token local é apagado.

Privacy Policy — Grana Exposta Studio

Last updated: September 29, 2026

Grana Exposta Studio is an internal tool used only by the owner of the Grana Exposta YouTube channel, running on the owner's own computer. It produces the channel's videos and, with the owner's authorization, uploads them to YouTube and reads the channel's analytics. The app has no other users and is not offered to the public.

YouTube API Services

This app uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data the app accesses

  • Video uploads (youtube.upload): uploads videos and thumbnails produced by the app to the owner's channel.
  • Channel read access (youtube.readonly): lists the owner's own videos (title, date, duration, view count).
  • Analytics (yt-analytics.readonly): reads aggregated metrics of the owner's own videos (views, watch time, retention, click-through rate, traffic sources).

The app does not access other channels' data or any viewer's personal data. YouTube Analytics metrics are aggregated and do not identify individuals.

How data is used

Metrics are used only by the owner to evaluate their own videos and improve future ones. Data is never sold, shared with third parties, or used for advertising.

Storage

The access token and metrics are stored only on the owner's computer, in a local folder that is not published or synced to any app server (the app has no servers). Metrics are refreshed periodically and can be deleted at any time.

Revoking access

Access can be revoked at any time with the app's Disconnect button (which also revokes the token at Google) or on the Google Account permissions page. Once revoked, the local token is deleted.
